# Player Guide (quick)

This quick guide explains how to interact with the prototype CLI and where to look for player-facing docs.

Running the prototype
- From the repo root run: `python -m handnfoot.handnfoot` (may be a minimal runner).

What to expect
- The prototype CLI demonstrates engine flows and may allow basic interactive play or scripted matches.

Player help
- Read `docs/rules.md` for rules and `docs/simulations.md` for how to run automated matches.

Feedback
- If the CLI behavior doesn't match the rules, open an issue and reference `_context/ARCHITECTURE.md` and `_context/ADRS/` if it's a design tradeoff.
